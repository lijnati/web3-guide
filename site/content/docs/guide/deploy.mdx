## Describe the deployment

Hardhat **Ignition** deploys contracts for you. You write a small file that says *what* to deploy:

```ts title="contracts/ignition/modules/MyContract.ts"
import { buildModule } from "@nomicfoundation/hardhat-ignition/modules";

export default buildModule("MyContractModule", (m) => {
  const initialValue = m.getParameter("initialValue", 1n);
  const myContract = m.contract("MyContract", [initialValue]);
  return { myContract };
});
```

- `m.contract("Name", [args])` deploys a contract with its constructor values.
- `m.getParameter(name, default)` lets you change those values without editing code.
- More than one contract? Call `m.contract` once for each.

Put the constructor values in a parameters file. Write `bigint` values as text ending in `n`:

```json title="contracts/ignition/parameters.json"
{ "MyContractModule": { "initialValue": "42n" } }
```

Add two deploy commands to `contracts/package.json`:

```json title="contracts/package.json"
"deploy:local": "hardhat ignition deploy ignition/modules/MyContract.ts --network localhost --parameters ignition/parameters.json",
"deploy:sepolia": "hardhat ignition deploy ignition/modules/MyContract.ts --network sepolia --parameters ignition/parameters.json"
```

## Deploy to a local chain

A local chain runs on your computer. It's instant, free, and resets when you stop it. Use it while you build the website.

<Steps>
<Step>

### Start the chain

In **terminal 1**:

```bash
npm run node
```

You should see `Started HTTP and WebSocket JSON-RPC server at http://127.0.0.1:8545/` and 20 test accounts. Leave it running.

<Callout type="warn">
  These test keys are public. Never send real money to them.
</Callout>

</Step>
<Step>

### Deploy

In **terminal 2**:

```bash
npm run deploy:local
```

You should see:

```text
[ MyContractModule ] successfully deployed 🚀

Deployed Addresses

MyContractModule#MyContract - 0x5FbDB2315678afecb367f032d93F642f64180aa3
```

**If it fails:**
- `ECONNREFUSED 127.0.0.1:8545` → the chain in terminal 1 isn't running.
- You restarted the chain → it was wiped. Deploy again.

</Step>
</Steps>

## Deploy to Sepolia

<Steps>
<Step>

### Get your private key

In MetaMask, pick your **Dev** account, then ⋮ → *Account details* → *Show private key*.

<Callout type="error" title="Use a test-only account">
  Only use an account with test ETH. Anyone with this key controls the account.
</Callout>

</Step>
<Step>

### Save your secrets in the Hardhat keystore

The keystore saves secrets encrypted, outside your project, so you can't push them to Git by accident.

```bash
npx hardhat keystore set SEPOLIA_RPC_URL
npx hardhat keystore set SEPOLIA_PRIVATE_KEY
npx hardhat keystore list
```

The first command asks you to pick a password. `list` should show both names.

<Accordions>
<Accordion title="Or use environment variables">

These only last until you close the terminal:

<Tabs items={["macOS / Linux", "Windows PowerShell"]}>
<Tab value="macOS / Linux">

```bash
export SEPOLIA_RPC_URL="https://eth-sepolia.g.alchemy.com/v2/<key>"
export SEPOLIA_PRIVATE_KEY="0x<key>"
```

</Tab>
<Tab value="Windows PowerShell">

```powershell
$env:SEPOLIA_RPC_URL = "https://eth-sepolia.g.alchemy.com/v2/<key>"
$env:SEPOLIA_PRIVATE_KEY = "0x<key>"
```

</Tab>
</Tabs>

</Accordion>
</Accordions>

</Step>
<Step>

### Test, then deploy

```bash
npm test
npm run deploy:sepolia
```

Confirm the network and enter your keystore password.

After 15–60 seconds you should see `successfully deployed 🚀` and your contract's address. Open `https://sepolia.etherscan.io/address/<your address>` to see it on the blockchain.

The address is also saved in `ignition/deployments/chain-11155111/deployed_addresses.json`. Commit this folder so your team can find it.

**If it fails:**
- `insufficient funds` → this account has no Sepolia ETH. Check you exported the right account.
- Timeout or `429 Too Many Requests` → use your own Alchemy or Infura RPC URL.
- It stopped halfway → run the same command again. It continues where it stopped.
- `Nothing new to deploy` after changing the contract → add `--reset` to deploy a new copy.

</Step>
</Steps>

<Callout title="Changed the contract?">
  Every change means a new address. Always do: **test → deploy → export the ABI → update the address** in the website.
</Callout>
