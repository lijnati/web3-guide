## Write an Ignition module

**What:** a file that describes *what* to deploy. Ignition handles *how*: sending transactions, waiting for confirmations, and remembering what's already deployed, so an interrupted deploy can resume.

```ts title="contracts/ignition/modules/MyContract.ts"
import { buildModule } from "@nomicfoundation/hardhat-ignition/modules";

export default buildModule("MyContractModule", (m) => {
  const initialValue = m.getParameter("initialValue", 1n);
  const myContract = m.contract("MyContract", [initialValue]);
  return { myContract };
});
```

- `m.contract("Name", [args])` deploys a contract with constructor arguments.
- `m.getParameter(name, default)` lets you change arguments per deployment without editing code.
- To deploy several contracts, call `m.contract` once for each. You can pass one contract as an argument to another, and Ignition deploys them in the right order.

Create a parameters file. The deploy scripts below read it, so it must exist. Write `bigint` values as strings ending in `n`:

```json title="contracts/ignition/parameters.json"
{ "MyContractModule": { "initialValue": "42n" } }
```

Add deploy scripts to `package.json`:

```json title="contracts/package.json"
"deploy:local": "hardhat ignition deploy ignition/modules/MyContract.ts --network localhost --parameters ignition/parameters.json",
"deploy:sepolia": "hardhat ignition deploy ignition/modules/MyContract.ts --network sepolia --parameters ignition/parameters.json"
```

## Deploy to a local chain

**Why:** a local chain mines instantly, gives you unlimited free ETH and resets on restart. Use it while you build the frontend.

<Steps>
<Step>

### Start the chain

In **terminal 1**:

```bash
npm run node
```

**Expected:** `Started HTTP and WebSocket JSON-RPC server at http://127.0.0.1:8545/`, followed by 20 accounts and their private keys. Leave it running.

<Callout type="warn">
  These keys are public and identical on every machine. Never send real funds to them.
</Callout>

</Step>
<Step>

### Deploy

In **terminal 2**:

```bash
npm run deploy:local
```

**Expected:**

```text
[ MyContractModule ] successfully deployed 🚀

Deployed Addresses

MyContractModule#MyContract - 0x5FbDB2315678afecb367f032d93F642f64180aa3
```

The first contract deployed on a fresh local chain is always at `0x5FbDB2315678afecb367f032d93F642f64180aa3`.

**If it fails:**
- `ECONNREFUSED 127.0.0.1:8545` → the node in terminal 1 isn't running.
- Restarted the node? The chain is wiped, so deploy again.

</Step>
</Steps>

## Deploy to Sepolia

<Steps>
<Step>

### Export a throwaway private key

In MetaMask, select your **Dev** account, then ⋮ → *Account details* → *Show private key*.

<Callout type="error" title="Testnet-only account">
  Use an account that holds only test ETH. Anyone with this key controls the account.
</Callout>

</Step>
<Step>

### Store secrets in the Hardhat keystore

**Why:** the keystore encrypts secrets in your home folder, outside the repository, so you can't commit them by accident. `configVariable("SEPOLIA_RPC_URL")` in the config reads from it.

```bash
npx hardhat keystore set SEPOLIA_RPC_URL
npx hardhat keystore set SEPOLIA_PRIVATE_KEY
npx hardhat keystore list
```

The first command asks you to create a keystore password. **Expected** from `list`: both names, without their values.

<Accordions>
<Accordion title="Alternative: environment variables">

`configVariable` also reads environment variables with the same name. They last only for the current terminal:

<Tabs items={["macOS / Linux", "Windows PowerShell"]}>
<Tab value="macOS / Linux">

```bash
export SEPOLIA_RPC_URL="https://eth-sepolia.g.alchemy.com/v2/<key>"
export SEPOLIA_PRIVATE_KEY="0x<key>"
```

</Tab>
<Tab value="Windows PowerShell">

```powershell
$env:SEPOLIA_RPC_URL = "https://eth-sepolia.g.alchemy.com/v2/<key>"
$env:SEPOLIA_PRIVATE_KEY = "0x<key>"
```

</Tab>
</Tabs>

</Accordion>
</Accordions>

</Step>
<Step>

### Test, then deploy

```bash
npm test
npm run deploy:sepolia
```

Confirm the network when Ignition asks, and enter your keystore password.

**Expected,** after 15–60 seconds: `successfully deployed 🚀` and your contract's address. Ignition also writes it to `ignition/deployments/chain-11155111/deployed_addresses.json`. Commit that folder so your team can find the address.

Open `https://sepolia.etherscan.io/address/<your address>` to see the contract creation.

**If it fails:**
- `insufficient funds` → the key's account has no Sepolia ETH. Check that you exported the account you funded.
- Timeouts or `429 Too Many Requests` → use your own Alchemy or Infura RPC URL.
- Interrupted → run the same command again. Ignition resumes instead of deploying twice.
- `Nothing new to deploy` after you changed the contract → add `--reset` to deploy a fresh copy at a new address.

</Step>
</Steps>

<Callout title="Every contract change means a new address">
  Changed the contract? Run **test → deploy → export the ABI → update the address** in the frontend. A stale ABI or address is the most common reason a dApp suddenly stops working.
</Callout>
