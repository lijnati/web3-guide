<Step>

### Copy the ABI into the website

The ABI tells the website which functions your contract has. This script copies it from `contracts/` into `web/lib`:

```js title="contracts/scripts/export-abi.mjs"
// Usage: node scripts/export-abi.mjs MyContract ../web/lib
// Copies a compiled contract's ABI into the frontend as a typed TypeScript module.
import { mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";

const [name = "MyContract", outDir = "../web/lib"] = process.argv.slice(2);

const artifact = JSON.parse(
  readFileSync(`artifacts/contracts/${name}.sol/${name}.json`, "utf8"),
);
const exportName = name[0].toLowerCase() + name.slice(1) + "Abi";
const outFile = join(outDir, `${exportName}.ts`);

mkdirSync(outDir, { recursive: true });
writeFileSync(
  outFile,
  `// Generated by scripts/export-abi.mjs. Do not edit by hand.\n` +
    `export const ${exportName} = ${JSON.stringify(artifact.abi, null, 2)} as const;\n`,
);
console.log(`Wrote ${artifact.abi.length} ABI items to ${outFile}`);
```

Run it from `contracts/`, after compiling:

```bash
node scripts/export-abi.mjs MyContract ../web/lib
```

You should see `Wrote 6 ABI items to ../web/lib/myContractAbi.ts` (the number depends on your contract).

The `as const` lets TypeScript catch a wrong function name before you run the app. **Run the script again after every contract change.**

</Step>
<Step>

### Set up wagmi

This tells wagmi which networks to use and how to connect wallets:

```ts title="web/lib/wagmi.ts"
import { createConfig, http } from "wagmi";
import { hardhat, sepolia } from "wagmi/chains";
import { injected } from "wagmi/connectors";

export const config = createConfig({
  chains: [sepolia, hardhat],
  connectors: [injected()],
  ssr: true,
  transports: {
    // Falls back to viem's public Sepolia RPC if you don't set your own.
    [sepolia.id]: http(process.env.NEXT_PUBLIC_SEPOLIA_RPC_URL),
    [hardhat.id]: http("http://127.0.0.1:8545"),
  },
});

declare module "wagmi" {
  interface Register {
    config: typeof config;
  }
}
```

- `injected()` connects browser wallets like MetaMask, Rabby and Brave.
- `ssr: true` is required in Next.js.
- The `declare module` part gives you type checking in every hook.

<Callout title="useAccount is now useConnection">
  wagmi v3 renamed `useAccount` to `useConnection`. Older tutorials and AI-written code still use `useAccount`.
</Callout>

</Step>
<Step>

### Describe your contract in one place

```ts title="web/lib/contract.ts"
import { getAddress, isAddress } from "viem";
import { hardhat, sepolia } from "wagmi/chains";
import { myContractAbi } from "./myContractAbi";

const chainId = Number(process.env.NEXT_PUBLIC_CHAIN_ID ?? sepolia.id);
const rawAddress = process.env.NEXT_PUBLIC_CONTRACT_ADDRESS ?? "";

/** The chain your contract is deployed on. */
export const targetChain = chainId === hardhat.id ? hardhat : sepolia;

/** `undefined` until NEXT_PUBLIC_CONTRACT_ADDRESS holds a valid address. */
export const contractAddress = isAddress(rawAddress) ? getAddress(rawAddress) : undefined;

export const myContract = {
  abi: myContractAbi,
  address: contractAddress,
  chainId: targetChain.id,
} as const;
```

Pass `...myContract` to every wagmi hook. Reads then work even when the user's wallet is on another network.

</Step>
<Step>

### Add the providers

wagmi hooks need two providers around your app. They only run in the browser, so the file starts with `"use client"`:

```tsx title="web/app/providers.tsx"
"use client";

import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { useState, type ReactNode } from "react";
import { WagmiProvider } from "wagmi";
import { config } from "@/lib/wagmi";

export function Providers({ children }: { children: ReactNode }) {
  // One QueryClient per browser session, never shared between server requests.
  const [queryClient] = useState(() => new QueryClient());

  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>
    </WagmiProvider>
  );
}
```

Wrap the app with them in `app/layout.tsx`:

```tsx title="web/app/layout.tsx"
import type { Metadata } from "next";
import "./globals.css";
import { Providers } from "./providers";

export const metadata: Metadata = { title: "My dApp" };

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html lang="en">
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

</Step>

### Add the contract address

```bash title="web/.env.local"
# 31337 = local Hardhat node, 11155111 = Sepolia
NEXT_PUBLIC_CHAIN_ID=31337
NEXT_PUBLIC_CONTRACT_ADDRESS=0x5FbDB2315678afecb367f032d93F642f64180aa3
# Optional: your own Sepolia RPC URL
NEXT_PUBLIC_SEPOLIA_RPC_URL=
```

- `NEXT_PUBLIC_*` values are visible to anyone using the site. Addresses are public anyway. **Never put a private key here.**
- Restart `npm run dev` after you change this file.

</Step>
