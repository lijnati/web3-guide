<Steps>
<Step>

### Create the Next.js app

From `my-dapp` (next to `contracts`):

```bash
npx create-next-app@latest web --ts --tailwind --eslint --app --no-src-dir --import-alias "@/*" --use-npm --yes
cd web
npm install wagmi viem@2 @tanstack/react-query
```

| Package | Job |
| --- | --- |
| `viem` | Talks to the chain: encodes calls with the ABI, sends RPC requests, decodes errors |
| `wagmi` | React hooks built on viem: `useConnection`, `useReadContract`, `useWriteContract`… |
| `@tanstack/react-query` | Caching and loading state for those hooks. wagmi requires it. |

Then open `tsconfig.json` and change `"target": "ES2017"` to `"target": "ES2020"`.

**Why:** contract numbers are `bigint`, and you'll write literals like `0n`. Below ES2020, TypeScript fails with *"BigInt literals are not available when targeting lower than ES2020"*.

<Callout title="wagmi v3 naming">
  wagmi v3 renamed `useAccount` to `useConnection`. Older tutorials and most AI-generated code still use `useAccount`, which is deprecated.
</Callout>

</Step>
<Step>

### Export the ABI to the frontend

**What:** a script in the contracts project that copies a compiled ABI into `web/lib` as a TypeScript constant.

**Why `as const`:** wagmi and viem infer exact function names, arguments and return types from it. A typo in a function name becomes a compile error instead of a runtime failure.

```js title="contracts/scripts/export-abi.mjs"
// Usage: node scripts/export-abi.mjs MyContract ../web/lib
// Copies a compiled contract's ABI into the frontend as a typed TypeScript module.
import { mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";

const [name = "MyContract", outDir = "../web/lib"] = process.argv.slice(2);

const artifact = JSON.parse(
  readFileSync(`artifacts/contracts/${name}.sol/${name}.json`, "utf8"),
);
const exportName = name[0].toLowerCase() + name.slice(1) + "Abi";
const outFile = join(outDir, `${exportName}.ts`);

mkdirSync(outDir, { recursive: true });
writeFileSync(
  outFile,
  `// Generated by scripts/export-abi.mjs. Do not edit by hand.\n` +
    `export const ${exportName} = ${JSON.stringify(artifact.abi, null, 2)} as const;\n`,
);
console.log(`Wrote ${artifact.abi.length} ABI items to ${outFile}`);
```

From `contracts`, after compiling:

```bash
node scripts/export-abi.mjs MyContract ../web/lib
```

**Expected:** `Wrote 6 ABI items to ../web/lib/myContractAbi.ts`. The count depends on your contract. Run it again after **every** contract change, once for each contract the frontend uses.

</Step>
<Step>

### Configure wagmi

**What:** one config object listing your chains, how to reach each one (transports) and which wallets can connect (connectors).

```ts title="web/lib/wagmi.ts"
import { createConfig, http } from "wagmi";
import { hardhat, sepolia } from "wagmi/chains";
import { injected } from "wagmi/connectors";

export const config = createConfig({
  chains: [sepolia, hardhat],
  connectors: [injected()],
  ssr: true,
  transports: {
    // Falls back to viem's public Sepolia RPC if you don't set your own.
    [sepolia.id]: http(process.env.NEXT_PUBLIC_SEPOLIA_RPC_URL),
    [hardhat.id]: http("http://127.0.0.1:8545"),
  },
});

declare module "wagmi" {
  interface Register {
    config: typeof config;
  }
}
```

- `injected()` connects any browser-extension wallet: MetaMask, Rabby, Brave and others. For mobile wallets, add `walletConnect({ projectId })` with a free project ID from Reown.
- `ssr: true` is required in Next.js to avoid hydration mismatches.
- The `declare module` block makes every hook type-safe for *your* chains.
- To use another chain (Base Sepolia, Arbitrum Sepolia…), import it from `wagmi/chains` and add it to both `chains` and `transports`. Add it to `networks` in `hardhat.config.ts` too.

</Step>
<Step>

### Describe your contract in one place

```ts title="web/lib/contract.ts"
import { getAddress, isAddress } from "viem";
import { hardhat, sepolia } from "wagmi/chains";
import { myContractAbi } from "./myContractAbi";

const chainId = Number(process.env.NEXT_PUBLIC_CHAIN_ID ?? sepolia.id);
const rawAddress = process.env.NEXT_PUBLIC_CONTRACT_ADDRESS ?? "";

/** The chain your contract is deployed on. */
export const targetChain = chainId === hardhat.id ? hardhat : sepolia;

/** `undefined` until NEXT_PUBLIC_CONTRACT_ADDRESS holds a valid address. */
export const contractAddress = isAddress(rawAddress) ? getAddress(rawAddress) : undefined;

export const myContract = {
  abi: myContractAbi,
  address: contractAddress,
  chainId: targetChain.id,
} as const;
```

Spread `myContract` into every hook call. Including `chainId` pins reads and writes to the contract's chain, so reads keep working even when the user's wallet is on another network.

</Step>
<Step>

### Add the providers

wagmi hooks need two React context providers. They use browser APIs, so they go in a client component:

```tsx title="web/app/providers.tsx"
"use client";

import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { useState, type ReactNode } from "react";
import { WagmiProvider } from "wagmi";
import { config } from "@/lib/wagmi";

export function Providers({ children }: { children: ReactNode }) {
  // One QueryClient per browser session, never shared between server requests.
  const [queryClient] = useState(() => new QueryClient());

  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>
    </WagmiProvider>
  );
}
```

Wrap the app in `app/layout.tsx`:

```tsx title="web/app/layout.tsx"
import type { Metadata } from "next";
import "./globals.css";
import { Providers } from "./providers";

export const metadata: Metadata = { title: "My dApp" };

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html lang="en">
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

</Step>

### Set environment variables

```bash title="web/.env.local"
# 31337 = local Hardhat node, 11155111 = Sepolia
NEXT_PUBLIC_CHAIN_ID=31337
NEXT_PUBLIC_CONTRACT_ADDRESS=0x5FbDB2315678afecb367f032d93F642f64180aa3
# Optional: your own Sepolia RPC URL
NEXT_PUBLIC_SEPOLIA_RPC_URL=
```

- `NEXT_PUBLIC_*` values are compiled into the browser bundle. That's fine for addresses and chain IDs, which are public anyway. **Never put a private key in one.**
- Next.js reads `.env.local` only at startup, so restart `npm run dev` after each change.
- Commit a `.env.example` with the same keys and empty values, so teammates know what to set. The generated `.gitignore` ignores `.env*`, so add the line `!.env.example`.

</Step>
