### Write your contract

Create `contracts/contracts/MyContract.sol`. This example has the parts most contracts use. Replace them with your own design from [Plan your dApp](/docs/guide/plan#design-the-functions-first).

```solidity title="contracts/contracts/MyContract.sol"
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

contract MyContract {
    address public immutable owner;
    uint256 public value;

    event ValueChanged(address indexed by, uint256 newValue);

    error ZeroValue();

    constructor(uint256 initialValue) {
        owner = msg.sender;
        value = initialValue;
    }

    function setValue(uint256 newValue) external {
        if (newValue == 0) revert ZeroValue();
        value = newValue;
        emit ValueChanged(msg.sender, newValue);
    }
}
```

| Solidity | In Web2 terms |
| --- | --- |
| State variable (`value`) | A database column, saved on the blockchain |
| `public` variable | Gets a free read function: `value()` |
| `external` function | A `POST` endpoint. Changes data and costs gas. |
| `view` function | A `GET` endpoint. Only reads, free. |
| `msg.sender` | The logged-in user (the address that signed) |
| `revert ZeroValue()` | `return 400`. Cancels every change in the call. |
| `event` / `emit` | A log line the website can read |
| `constructor` | Runs once, when you deploy |

</Step>

### Common patterns

**Only the owner can call a function:**

```solidity
error NotOwner();

modifier onlyOwner() {
    if (msg.sender != owner) revert NotOwner();
    _;
}

function withdraw() external onlyOwner { /* … */ }
```

**Accept ETH:**

```solidity
mapping(address => uint256) public paid;

event Paid(address indexed from, uint256 amount);

function pay() external payable {
    require(msg.value > 0, "Send some ETH");
    paid[msg.sender] += msg.value;
    emit Paid(msg.sender, msg.value);
}
```

**Save data per user:** use `mapping(address => YourType)`. You can't loop over a mapping. If the website needs a full list, also keep an array or emit events.

**Tokens and NFTs:** don't write them yourself. Install [OpenZeppelin Contracts](https://docs.openzeppelin.com/contracts) (`npm install @openzeppelin/contracts`) and build on their tested code.

<Callout type="warn" title="Keep it small">
  Contract code is public, can't be changed, and costs gas to deploy. Only return arrays that stay small.
</Callout>

</Step>
<Step>

### Compile

```bash
npm run compile
```

You should see:

```text
Compiled 1 Solidity file with solc 0.8.28 (evm target: cancun)
```

The first run downloads the compiler. The result goes to `artifacts/`. The file `artifacts/contracts/MyContract.sol/MyContract.json` holds the **ABI** your website needs.

**If it fails:**
- `ParserError` or `DeclarationError` → a typo in your Solidity. The error shows the file, line and column.
- `Cannot find module ... hardhat-toolbox-viem` → you're not in the `contracts` folder, or the install didn't finish.
- `require() of ES Module` → `"type": "module"` is missing from `package.json`.
- A version error → the `pragma` line must match `solidity.version` in the config.
