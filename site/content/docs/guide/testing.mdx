---
title: Test your contract
description: Check that every rule in your contract works before you deploy.
---

You can't edit a contract after you deploy it. Tests run on a fake blockchain in seconds and cost nothing, so find bugs here.

## Write a test file

Create one test file per contract in `contracts/test/`:

```ts title="contracts/test/MyContract.ts"
import assert from "node:assert/strict";
import { describe, it } from "node:test";
import { network } from "hardhat";

const { viem } = await network.create();

describe("MyContract", async function () {
  it("stores the initial value and the owner", async function () {
    const [deployer] = await viem.getWalletClients();
    const myContract = await viem.deployContract("MyContract", [42n]);

    assert.equal(await myContract.read.value(), 42n);
    assert.equal(
      (await myContract.read.owner()).toLowerCase(),
      deployer.account.address.toLowerCase(),
    );
  });

  it("updates the value and emits ValueChanged", async function () {
    const [deployer] = await viem.getWalletClients();
    const myContract = await viem.deployContract("MyContract", [1n]);

    await viem.assertions.emitWithArgs(
      myContract.write.setValue([7n]),
      myContract,
      "ValueChanged",
      [deployer.account.address, 7n],
    );
    assert.equal(await myContract.read.value(), 7n);
  });

  it("reverts with ZeroValue for 0", async function () {
    const myContract = await viem.deployContract("MyContract", [1n]);
    await viem.assertions.revertWithCustomError(
      myContract.write.setValue([0n]),
      myContract,
      "ZeroValue",
    );
  });

  it("lets any account call setValue", async function () {
    const [, other] = await viem.getWalletClients();
    const myContract = await viem.deployContract("MyContract", [1n]);

    await myContract.write.setValue([5n], { account: other.account });
    assert.equal(await myContract.read.value(), 5n);
  });
});
```

## What each part does

| Code | What it does |
| --- | --- |
| `network.create()` | Starts a fake blockchain with 20 test accounts full of ETH |
| `viem.deployContract("Name", [args])` | Deploys your contract |
| `contract.read.fn()` / `contract.write.fn([args])` | Calls a function |
| `viem.getWalletClients()` | The test accounts. Pass `{ account }` to call as a different user. |
| `viem.assertions.emitWithArgs(...)` | Checks that an event was sent |
| `viem.assertions.revertWithCustomError(...)` | Checks that a call failed with a specific error |

Numbers are `bigint`, so write `42n`, not `42`.

## What to test

For each function that changes data, test:

1. **It works:** the data changes as expected.
2. **Each rule:** one test for every `revert` or `require`.
3. **Who can call it:** other users are blocked, if only the owner should call it.
4. **Events:** sent with the right values.
5. **Money:** balances before and after, for `payable` functions.

## Run the tests

```bash
npm test
```

You should see:

```text
Running node:test tests

  MyContract
    ✔ stores the initial value and the owner
    ✔ updates the value and emits ValueChanged
    ✔ reverts with ZeroValue for 0
    ✔ lets any account call setValue


4 passing (4 nodejs)
```

`npm test` compiles first, so you don't need to compile separately.

**If it fails:**
- `Expected 0n but got 0` → compare with a `bigint`, like `0n`.
- Artifact not found → the name in `deployContract` must match the contract name exactly, including capital letters.
- Your constructor needs values → pass them as the second argument: `deployContract("MyContract", [42n])`.
