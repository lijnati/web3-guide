## Wait until the page loads in the browser

The server can't see the user's wallet, so it always shows "not connected". If the browser shows "connected" right away, React throws a **hydration error**. This hook tells you when it's safe to show wallet info:

```ts title="web/lib/use-mounted.ts"
import { useSyncExternalStore } from "react";

const subscribe = () => () => {};

/** false during SSR and hydration, true afterwards. */
export function useMounted() {
  return useSyncExternalStore(subscribe, () => true, () => false);
}
```

## The connect button

```tsx title="web/components/wallet-button.tsx"
"use client";

import { useConnect, useConnection, useConnectors, useDisconnect } from "wagmi";
import { explainError } from "@/lib/errors";
import { useMounted } from "@/lib/use-mounted";

export function WalletButton() {
  const mounted = useMounted();
  const { address, isConnected } = useConnection();
  const connectors = useConnectors();
  const connect = useConnect();
  const disconnect = useDisconnect();

  // Wallet state only exists in the browser; render a stable placeholder on the server.
  if (!mounted) return <span>…</span>;

  if (isConnected && address) {
    return (
      <button onClick={() => disconnect.mutate()}>
        {address.slice(0, 6)}…{address.slice(-4)} · Disconnect
      </button>
    );
  }

  const injected = connectors[0];
  return (
    <div>
      <button disabled={connect.isPending} onClick={() => connect.mutate({ connector: injected })}>
        {connect.isPending ? "Check your wallet…" : "Connect wallet"}
      </button>
      {connect.error && (
        <p role="alert">
          {/no provider|not found/i.test(connect.error.message)
            ? "No browser wallet found. Install MetaMask."
            : explainError(connect.error)}
        </p>
      )}
    </div>
  );
}
```

`explainError` comes from [Read & write](/docs/guide/read-write#show-clear-error-messages).

| When | Show |
| --- | --- |
| Page still loading | A placeholder |
| Not connected | "Connect wallet" |
| Waiting for the user | "Check your wallet…" |
| No wallet, or user said no | A short message |
| Connected | Short address + Disconnect |

## Wrong network? Offer a switch

The user's wallet can be on any network. Check it before allowing writes:

```tsx
import { useConnection, useSwitchChain } from "wagmi";
import { targetChain } from "@/lib/contract";

const { isConnected, chainId } = useConnection();
const switchChain = useSwitchChain();
const wrongChain = mounted && isConnected && chainId !== targetChain.id;

{wrongChain && (
  <button
    disabled={switchChain.isPending}
    onClick={() => switchChain.mutate({ chainId: targetChain.id })}
  >
    {switchChain.isPending ? "Check your wallet…" : `Switch to ${targetChain.name}`}
  </button>
)}
```

## Try it with MetaMask on your local chain

1. **Add the network** in MetaMask → *Add a network manually*:
   - RPC URL: `http://127.0.0.1:8545`
   - Chain ID: `31337`
   - Currency symbol: `ETH`
2. **Import a test account:** *Add account → Import account*, and paste Account #0's private key from `npm run node`. It has 10,000 test ETH.
3. Run `npm run dev` in `web`, open [localhost:3000](http://localhost:3000) and click **Connect wallet**.

**If it fails:**
- Nothing happens → MetaMask is locked or its popup is hidden. Click the MetaMask icon.
- Hydration error → you showed wallet info before `mounted` was true, or `ssr: true` is missing.
- `useConfig must be used within WagmiProvider` → the component isn't inside `<Providers>`, or the file is missing `"use client"`.
- `Nonce too high` after restarting the chain → MetaMask *Settings → Advanced → Clear activity tab data*.
