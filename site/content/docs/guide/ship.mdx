<Steps>
<Step>

### Point the website at Sepolia

After you [deploy to Sepolia](/docs/guide/deploy#deploy-to-sepolia), update `web/.env.local`:

```bash title="web/.env.local"
NEXT_PUBLIC_CHAIN_ID=11155111
NEXT_PUBLIC_CONTRACT_ADDRESS=0x…your Sepolia address…
NEXT_PUBLIC_SEPOLIA_RPC_URL=https://eth-sepolia.g.alchemy.com/v2/<key>
```

Restart `npm run dev`, switch MetaMask to Sepolia, and try everything once.

<Callout title="Is it safe to put the RPC key here?">
  Anyone using your site can see it. A free key is fine for a demo. For a real project, limit the key to your domain in the Alchemy or Infura dashboard.
</Callout>

</Step>
<Step>

### Build it on your computer

```bash
npm run lint
npm run build
```

You should see `✓ Compiled successfully`. Fix errors here, it's faster than on Vercel.

**If it fails:**
- Type error on `functionName` or `args` → the ABI is old. Export it again.
- `Module not found: @/lib/myContractAbi` → the ABI file isn't committed.

</Step>
<Step>

### Push to GitHub

```bash
git status   # .env.local must NOT be listed
git add .
git commit -m "My dApp"
git push
```

Commit `contracts/ignition/deployments/` and `web/lib/*Abi.ts`. Never commit `.env.local` or a private key.

</Step>
<Step>

### Deploy to Vercel

1. Go to [vercel.com/new](https://vercel.com/new) and import your repository.
2. Set **Root Directory** to `web`. The build fails without this.
3. Add the variables from `.env.local`.
4. Click **Deploy**.

You get a `https://<project>.vercel.app` link. Data should load even without a wallet.

Changed a variable in Vercel? Redeploy: *Deployments → ⋯ → Redeploy*.

</Step>
</Steps>

## Launch checklist

- [ ] All tests pass
- [ ] Contract is on Sepolia and shows on Etherscan
- [ ] ABI exported after the last contract change
- [ ] Website uses the latest Sepolia address and chain `11155111`
- [ ] `npm run build` works on your computer
- [ ] Vercel: Root Directory is `web`, variables are set
- [ ] The live site loads data in a private window, with no wallet
- [ ] A write works on the live site with MetaMask
- [ ] No private keys in Git

## What next

- **Verify your contract** on Etherscan so people can read its code. See the [Hardhat docs](https://hardhat.org/docs).
- **Use tested code** for tokens, NFTs and permissions: [OpenZeppelin Contracts](https://docs.openzeppelin.com/contracts).
- **Learn more:** [Hardhat](https://hardhat.org/docs), [wagmi](https://wagmi.sh), [viem](https://viem.sh), [Next.js](https://nextjs.org/docs).
