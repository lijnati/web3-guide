## Create the folder and repository

```bash
mkdir my-dapp
cd my-dapp
git init
```

Add a `.gitignore` before anything else, so secrets and generated files never reach Git:

```text title="my-dapp/.gitignore"
node_modules
.env*
.next
artifacts
cache
types
```

**Expected:** `Initialized empty Git repository in .../my-dapp/.git/`.

<Callout type="warn" title="Never commit keys">
  A private key pushed to a public repository is drained within minutes. `.env*` in `.gitignore` keeps `.env.local` out, and Hardhat keeps its own secrets outside the project.
</Callout>

## How the pieces connect

```text
 contracts/MyContract.sol ──build──▶ ABI ──export──▶ web/lib/myContractAbi.ts ─┐
            │                                                                   ├──▶ wagmi hooks
            └──deploy──▶ contract address ──▶ web/.env.local ───────────────────┘
```

The frontend needs exactly two facts about your contract: its **ABI** (which functions exist) and its **address** (where it lives). If either is out of date, nothing works. Each time you change the contract, export the ABI again and update the address.
