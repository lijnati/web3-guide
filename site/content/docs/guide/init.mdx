A dApp has two parts, kept side by side in one folder:

- **`contracts/`**: the smart contract. Built with **Hardhat**.
- **`web/`**: the website. Built with **Next.js** and **wagmi**.

At the end of this page, both parts are installed and running. The next pages fill them in.

<Steps>
<Step>

### Create the project folder

```bash
mkdir my-dapp
cd my-dapp
git init
```

Create a `.gitignore` so secrets and generated files never go into Git:

```text title="my-dapp/.gitignore"
node_modules
.env*
.next
artifacts
cache
types
```

</Step>
<Step>

### Set up the contract project

Hardhat is the tool that compiles, tests and deploys your contract. Install it in `contracts/`:

```bash
mkdir contracts
cd contracts
npm init -y
npm pkg set type=module
npm install --save-dev hardhat @nomicfoundation/hardhat-toolbox-viem
npm install --save-dev @nomicfoundation/hardhat-ignition viem typescript @types/node
npm pkg set scripts.compile="hardhat build" scripts.test="hardhat test" scripts.node="hardhat node"
```

- `type=module` is required. Hardhat 3 only works with ES modules.
- `hardhat-toolbox-viem` adds testing and deploying tools.
- The last line adds `npm run compile`, `npm test` and `npm run node`.

Create the Hardhat config:

```ts title="contracts/hardhat.config.ts"
import hardhatToolboxViemPlugin from "@nomicfoundation/hardhat-toolbox-viem";
import { configVariable, defineConfig } from "hardhat/config";

export default defineConfig({
  plugins: [hardhatToolboxViemPlugin],
  solidity: {
    version: "0.8.28",
  },
  networks: {
    // `npx hardhat node` serves this chain at http://127.0.0.1:8545 (chain id 31337)
    localhost: {
      type: "http",
      chainType: "l1",
      url: "http://127.0.0.1:8545",
    },
    sepolia: {
      type: "http",
      chainType: "l1",
      url: configVariable("SEPOLIA_RPC_URL"),
      accounts: [configVariable("SEPOLIA_PRIVATE_KEY")],
    },
  },
});
```

- **`plugins`**: Hardhat 3 only loads plugins listed here.
- **`networks`**: where you can deploy. `localhost` is a test chain on your computer. `sepolia` is the public test network.
- **`configVariable(...)`**: a secret you fill in later, when you [deploy to Sepolia](/docs/guide/deploy#deploy-to-sepolia). You don't need it to compile or test.

Create a `tsconfig.json` so your editor understands the TypeScript files:

```json title="contracts/tsconfig.json"
{
  "compilerOptions": {
    "lib": ["es2023"],
    "module": "node16",
    "target": "es2022",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "moduleResolution": "node16",
    "noEmit": true
  }
}
```

**Check it:**

```bash
npx hardhat --version
```

You should see `3.x.x`.

</Step>
<Step>

### Set up the website

Go back to `my-dapp` and create a Next.js app called `web`:

```bash
cd ..
npx create-next-app@latest web --ts --tailwind --eslint --app --no-src-dir --import-alias "@/*" --use-npm --yes
cd web
npm install wagmi viem@2 @tanstack/react-query
```

| Package | What it does |
| --- | --- |
| `viem` | Talks to the blockchain |
| `wagmi` | React hooks for wallets and contracts, built on viem |
| `@tanstack/react-query` | Handles loading and caching. wagmi needs it. |

Open `web/tsconfig.json` and change `"target": "ES2017"` to `"target": "ES2020"`. Contract numbers are `bigint` (like `0n`), and older targets don't support them.

**Check it:**

```bash
npm run dev
```

Open [localhost:3000](http://localhost:3000). You should see the Next.js starter page. Stop it with `Ctrl+C`.

</Step>
</Steps>

- **`contracts/`**: Hardhat, the smart contract. `contracts/` holds the Solidity code, `test/` the tests, `scripts/` helper scripts.
- **`web/`**: Next.js, the website. `lib/` holds the contract ABI and the wagmi setup.

The `.sol`, test, script and `lib/` files don't exist yet. The next pages add them.

The next pages add the contract, its tests and deploy files to `contracts/`, and the wallet and contract code to `web/`.

## How the two parts connect

```text
 contracts/MyContract.sol ──build──▶ ABI ──export──▶ web/lib/myContractAbi.ts ─┐
            │                                                                   ├──▶ wagmi hooks
            └──deploy──▶ contract address ──▶ web/.env.local ───────────────────┘
```

The website needs two things from the contract:

- the **ABI**: a list of the contract's functions
- the **address**: where the contract lives on the blockchain

Each time you change the contract, update both.
