title: Set up your machine
description: Install the tools, create a dev wallet, and get Sepolia test ETH.
---

<Callout type="warn" title="Get test ETH early">
  Faucets can be slow or rate-limited. Request Sepolia ETH well before you need to deploy.
</Callout>

<Steps>
<Step>

### Install Node.js 22 or newer

**Why:** Hardhat 3 and Next.js 16 both need a recent Node.js. Older versions fail with confusing syntax errors.

Download the LTS version from [nodejs.org](https://nodejs.org), then check it:

```bash
node -v
npm -v
```

**Expected:** `v22.x.x` or higher (`v24` is fine).

**If it fails:** if you see `v18` or `v20`, your old Node is still first on your `PATH`. Close every terminal, open a new one and check again. If you use `nvm`, run `nvm install 22 && nvm use 22`.

</Step>
<Step>

### Install Git and an editor

Install [Git](https://git-scm.com) and [VS Code](https://code.visualstudio.com). In VS Code, add the **Solidity** extension by Nomic Foundation to get syntax highlighting and inline compiler errors.

```bash
git --version
```

</Step>
<Step>

### Install MetaMask and create a dev account

**Why:** MetaMask is the wallet your dApp connects to. It holds your keys and signs transactions.

1. Install the extension from [metamask.io](https://metamask.io).
2. Create a wallet and save the recovery phrase offline.
3. Create a **second account** called `Dev`. Use only this account for development.
4. Turn on test networks: open the network menu, enable **Show test networks**, then select **Sepolia**.

**Expected:** MetaMask shows *Sepolia* and a balance of `0 SepoliaETH`.

</Step>
<Step>

### Get Sepolia test ETH

**Why:** every write and deployment costs gas. On Sepolia, gas is paid with free test ETH.

Copy your `Dev` address from MetaMask and request ETH from a faucet. Try them in order until one works:

- [Google Cloud Web3 faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia)
- [Alchemy Sepolia faucet](https://www.alchemy.com/faucets/ethereum-sepolia)
- [Infura faucet](https://www.infura.io/faucet/sepolia)

**Expected:** 0.05 SepoliaETH or more after a minute. That is enough for dozens of deployments.

**If it fails:** some faucets need a small mainnet balance or a login. Try the next one, or ask a teammate to send you 0.05 SepoliaETH.

</Step>
<Step>

### Get an RPC URL (recommended)

**Why:** public RPCs are shared and rate-limited. During a demo, a free personal RPC is much more reliable.

Create a free app on [Alchemy](https://www.alchemy.com) or [Infura](https://www.infura.io), choose **Ethereum Sepolia**, and copy the HTTPS URL. It looks like:

```text
https://eth-sepolia.g.alchemy.com/v2/<your-key>
```

Keep it somewhere private. You will use it when you [deploy to Sepolia](/docs/guide/deploy#deploy-to-sepolia).

</Step>
</Steps>

## Checklist

- [ ] `node -v` prints v22 or newer
- [ ] MetaMask installed with a separate `Dev` account
- [ ] Sepolia selected, balance above 0
- [ ] Sepolia RPC URL saved
