---
title: Set up your computer
description: Install the tools, create a test wallet, and get free test ETH.
---

<Callout type="warn" title="Get test ETH early">
  Faucets can be slow. Ask for test ETH well before you need it.
</Callout>

<Steps>
<Step>

### Install Node.js 22 or newer

Download the LTS version from [nodejs.org](https://nodejs.org), then check it:

```bash
node -v
```

You should see `v22` or higher.

**Still see `v18` or `v20`?** Close all terminals and open a new one. If you use `nvm`, run `nvm install 22 && nvm use 22`.

</Step>
<Step>

### Install Git and VS Code

Install [Git](https://git-scm.com) and [VS Code](https://code.visualstudio.com). In VS Code, add the **Solidity** extension by Nomic Foundation.

</Step>
<Step>

### Install MetaMask and make a test account

MetaMask is the wallet your dApp connects to.

1. Install it from [metamask.io](https://metamask.io).
2. Create a wallet. Write the recovery phrase down and keep it offline.
3. Add a **second account** called `Dev`. Use only this one for development.
4. In the network menu, turn on **Show test networks** and pick **Sepolia**.

You should see *Sepolia* and `0 SepoliaETH`.

</Step>
<Step>

### Get free test ETH

Every write costs a small fee. On Sepolia, you pay it with free test ETH.

Copy your `Dev` address and paste it into a faucet. If one doesn't work, try the next:

- [Google Cloud faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia)
- [Alchemy faucet](https://www.alchemy.com/faucets/ethereum-sepolia)
- [Infura faucet](https://www.infura.io/faucet/sepolia)

0.05 SepoliaETH is enough for many deploys.

</Step>
<Step>

### Get an RPC URL

Public servers are slow and shared. A free personal one is more reliable.

Make a free app on [Alchemy](https://www.alchemy.com) or [Infura](https://www.infura.io), choose **Ethereum Sepolia**, and copy the HTTPS URL:

```text
https://eth-sepolia.g.alchemy.com/v2/<your-key>
```

Keep it private. You'll use it when you [deploy to Sepolia](/docs/guide/deploy#deploy-to-sepolia).

</Step>
</Steps>

## Checklist

- [ ] `node -v` shows v22 or newer
- [ ] MetaMask has a separate `Dev` account
- [ ] Sepolia is selected and you have test ETH
- [ ] You saved your Sepolia RPC URL
