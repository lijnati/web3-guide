This guide shows you how to build **your own** decentralized application, from an idea to a contract on Sepolia and a live frontend. It doesn't walk you through a fixed sample app. Each page explains one part of the stack, what it is for, how to set it up and how to tell it's working.

Code samples use placeholder names: `MyContract`, `value` and `setValue`. Replace them with your own contract, functions and arguments.

## How a dApp fits together

```text
 Your Next.js app ──(wagmi + viem)──▶ RPC node ──▶ Ethereum (Sepolia)
        │                                              ▲
        └── asks the wallet to sign ──▶ MetaMask ──────┘
```

- The **smart contract** is your backend. It holds the rules and the data.
- The **frontend** reads from the contract for free and asks the user's **wallet** to sign anything that changes state.
- **Hardhat** compiles, tests and deploys the contract. **wagmi** and **viem** connect the frontend to it.

## Stack

| Tool | Version | Role |
| --- | --- | --- |
| Node.js | 22 or newer | Runs everything |
| Hardhat | 3.x | Compile, test and deploy contracts |
| Solidity | 0.8.28 | Contract language |
| viem | 2.x | TypeScript library for Ethereum |
| wagmi | 3.x | React hooks for wallets and contracts |
| Next.js | 16.x | Frontend framework |
| MetaMask | latest | Browser wallet |
