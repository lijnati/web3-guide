This guide shows you how to build your own dApp: a smart contract on Ethereum and a website that uses it. If you've built a website before, you're ready.

The code uses example names: `MyContract`, `value` and `setValue`. Change them to your own.

## How a dApp works

```text
 Your website ──(wagmi + viem)──▶ RPC server ──▶ Ethereum (Sepolia)
      │                                              ▲
      └── asks the wallet to approve ──▶ MetaMask ───┘
```

- The **smart contract** is your backend. It keeps the data and the rules.
- The **website** reads the contract for free. To change data, it asks the user's **wallet** to approve.
- **Hardhat** builds, tests and deploys the contract. **wagmi** and **viem** connect the website to it.
