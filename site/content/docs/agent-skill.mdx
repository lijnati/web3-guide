The **web3-dapp** skill turns this guide into instructions for AI coding agents. Ask your agent to "start a new dApp" and it will:

- set up Hardhat 3 and Next.js like this guide
- write and test your contract
- add the wallet button and the read/write UI
- run real checks (compile, test, lint, build) after each step

It works with Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf, OpenCode, Cline and other agents that support [Agent Skills](https://agentskills.io).

## Install

Run this in the folder where you'll build your dApp:

```bash
npx skills add lijnati/web3-guide --skill web3-dapp
```

It finds the agents you have and installs the skill for each. Useful flags:

| Flag | What it does |
| --- | --- |
| `-a claude-code` | Install for one agent only |
| `-g` | Install for all your projects |
| `-y` | Skip the questions |

<Accordions>
<Accordion title="Install by hand">

Copy the `skills/web3-dapp` folder from the [repository](https://github.com/lijnati/web3-guide/tree/main/skills/web3-dapp) into your agent's skills folder:

| Agent | Folder |
| --- | --- |
| Claude Code | `.claude/skills/web3-dapp/` |
| Cursor, GitHub Copilot, OpenCode, Cline and others | `.agents/skills/web3-dapp/` |

## Use it

Describe your idea in plain words:

```text
Start a new dApp where students can register for events and the organizer
can close registration. Use the web3-dapp skill.
```

In Claude Code you can also type `/web3-dapp`.

The agent will:

1. Ask what the contract should store, what users can do, and who can do it.
2. Create `contracts/`, write the contract and tests, and run them.
3. Deploy to a local chain.
4. Create `web/`, connect it to the contract, and build the wallet and contract UI.
5. Run lint and a production build.
6. Leave the Sepolia deploy to you, because it needs your private key.

<Callout type="warn" title="You keep your secrets">
  The skill tells agents never to touch private keys or commit `.env.local`. Deploy to Sepolia yourself with [Deploy your contract](/docs/guide/deploy#deploy-to-sepolia).
</Callout>
