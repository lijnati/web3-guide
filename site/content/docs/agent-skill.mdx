The **web3-dapp** skill packs this guide into instructions a coding agent can follow. Ask your agent to "start a new dApp", and it will:

- set up Hardhat 3 and Next.js the same way this guide does
- write and test your contract
- wire up the wallet and the read/write UI
- check each step with real commands (compile, test, lint, build) before moving on

It follows the open [Agent Skills](https://agentskills.io) format: a `SKILL.md` file with two reference files. It works with Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf, OpenCode, Cline and other agents that support skills.

## Install

Run this in the folder where you'll build your dApp:

```bash
npx skills add lijnati/web3-guide --skill web3-dapp
```

The [skills CLI](https://github.com/vercel-labs/skills) detects which agents you have installed and copies the skill into each one's skills folder. Useful flags:

| Flag | Effect |
| --- | --- |
| `-a claude-code` | Install for one agent only. Repeat it to name several. |
| `-g` | Install for your user account, so it's available in every project |
| `-y` | Skip the confirmation prompts |

## Use it

Describe your idea in plain words. For example:

```text
Start a new dApp where students can register for events and the organizer
can close registration. Use the web3-dapp skill.
```

Most agents load the skill automatically when your request matches its description. In Claude Code, you can also run it directly with `/web3-dapp`.

The agent will:

1. Ask what the contract should store, what users can do, and who may do it.
2. Create `contracts/` (Hardhat 3), write the contract and its tests, then run `npm test`.
3. Deploy to a local chain with Ignition.
4. Create `web/` (Next.js + wagmi), export the ABI, and build the wallet and contract UI.
5. Run lint and a production build.
6. Hand the Sepolia deployment back to you, because it needs your private key and keystore password.

<Callout type="warn" title="You stay in charge of secrets">
  The skill tells agents never to run keystore commands, handle private keys or commit `.env.local`. Deploy to Sepolia yourself by following [Deploy your contract](/docs/guide/deploy#deploy-to-sepolia).
</Callout>

## What's inside

| File | Contents |
| --- | --- |
| `SKILL.md` | The workflow, the checks to run after each step, the rules that prevent common failures, and when the work counts as done |
| `references/contracts.md` | Hardhat config, contract skeleton, tests, Ignition module, ABI export script |
| `references/frontend.md` | wagmi config, providers, wallet button, read/write component, error handling |

The templates match the code in this guide, and both were tested against a local Hardhat chain.
